# Reference: Answerbox Code Mapping (ZONE 4)

## ⚠️ MULTIPART CONVENTION — Always Apply First

`qtype.txt` defaults to `multipart`. This means **every** ZONE 4 variable must use array indexing:

```php
$anstypes[0] = "calculated";   // ✅ array syntax
$answer[0]   = $val;

// ❌ NEVER scalar syntax in multipart:
// $anstypes = "calculated";
// $answer = $val;
```

> If `qtype.txt` contains a single type name (e.g. `calculated`), scalar syntax is valid. For all standard IMathAS5 agent work, assume **multipart** unless `qtype.txt` says otherwise.

## ✅ ZONE 4 Global Checklist

Before finalizing ZONE 4:

- [ ] All variables use array indexing `[i]` — multipart is default
- [ ] `$answer[i]` holds the **raw grading value** (numeric expression or string the engine evaluates)
- [ ] `$showanswer[i]` set when display format differs from raw value
- [ ] `$anstypes[i]` matches exactly one entry from the Type Index above
- [ ] For `numfunc`: `$variables[i]` declared AND `$domain[i]` explicitly set
- [ ] For `multans` and `matching`: using `$answers[i]` (PLURAL), not `$answer[i]`
- [ ] For `choices`/`multans`: correct answer is the **index** (0-based) into `$questions[i]`
