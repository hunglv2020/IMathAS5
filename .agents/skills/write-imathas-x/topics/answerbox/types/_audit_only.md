# Audit-Only Answer Types

These types are **not generated by question_gen**. They may appear in questions written by other authors. The agent must be able to read, understand, and audit them — but should never generate them when the `calculated`-family equivalent exists.

---

## `"number"` — Simple Numeric Entry

Like `calculated`, but **rejects expression-style input** (`2/3`, `5^2`). Student must enter a plain decimal or integer.

```php
$anstypes[i] = "number";
$answer[i]   = 5;
$abstolerance[i] = 0.01;
```

> **When auditing:** Acceptable when the question explicitly asks for a decimal value only. Otherwise, `calculated` is more student-friendly.

---

## `"interval"` — Interval Notation (Plain Numbers Only)

Like `calcinterval`, but **rejects expression endpoints** (`sqrt(8)` is not accepted).

```php
$anstypes[i] = "interval";
$answer[i]   = "(-oo, 4]U(5, oo)";
```

> **When auditing:** Valid if all endpoints are guaranteed to be plain numbers. Prefer `calcinterval` for future questions.

---

## `"ntuple"` — N-Tuple (Plain Numbers Only)

Like `calcntuple`, but **rejects expression components** (`1/3` is not accepted).

```php
$anstypes[i] = "ntuple";
$answer[i]   = "(2, 3)";
$displayformat[i] = "point";
```

> **When auditing:** Valid for integer/decimal coordinate points. Prefer `calcntuple`.

---

## `"complex"` — Complex Number (Plain Numbers Only)

Like `calccomplex`, but accepts only integer/decimal coefficients.

```php
$anstypes[i] = "complex";
$answer[i]   = "3+2i";
```

> **When auditing:** Valid when coefficients are guaranteed integers or simple decimals.

---

## `"matrix"` — Numerical Matrix (Plain Numbers Only)

Like `calcmatrix`, but **rejects expression entries**.

```php
$anstypes[i] = "matrix";
$answer[i]   = "[(1,2),(3,4)]";
$answersize[i] = "2,2";
```

> **When auditing:** Valid for matrices with guaranteed integer/decimal entries.

---

## `"essay"` — Free Response (Not Auto-Graded)

Student types a free-form text response. **Never auto-graded — requires manual review.**

```php
$anstypes[i]   = "essay";
$answerboxsize[i] = "5,60";   // rows, columns
```

Variables: `$answerboxsize[i]`, `$displayformat[i]` (`"editor"` for rich text), `$scoremethod[i]` (`"takeanything"` for auto full-credit).

> **When auditing:** Intentional for open-ended responses. Flag if used where auto-grading was expected.

---

## `"file"` — File Upload (Not Auto-Graded)

Student uploads a file (image, PDF, etc.). **Never auto-graded.**

```php
$anstypes[i] = "file";
```

> **When auditing:** Intentional for lab reports, drawings, etc. Flag if used in a context expecting auto-grading.
