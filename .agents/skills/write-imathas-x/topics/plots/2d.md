# Reference: IMathAS 2D Plots

Covers generating 2-dimensional plots in IMathAS `control.php`. Every function signature here has been **verified via the lookup script and live seed testing**.

---

## ⚠️ IMATHAS HARD RULES (Read Before Writing Any Plot Code)

These are **engine-level restrictions** that will cause fatal errors if violated:

| Rule | ❌ Wrong | ✅ Correct |
|---|---|---|
| No PHP open tag | `<?php` at top of file | Control files have no tag |
| No `while` | `while ($cond) { ... }` | `{} where condition` syntax |
| No `foreach` | `foreach ($arr as $v)` or `foreach ($arr as $k => $v)` | `for ($i = 0..$n) { $arr[$i] }` |
| No `array_merge` | `array_merge($a, $b)` | Two separate `showplot` calls + `mergeplots` |

---

## 1. MANDATORY RULE A: ALWAYS SET AXIS LABELS

Every plot **MUST** have named axis labels. Use **one of two methods**:

### Method 1 — String format in `showplot` param `xlabels` *(preferred)*
```php
// Format: "grid_x:grid_y:xlabel:ylabel"
$plot = showplot($funcs, xmin, xmax, ymin, ymax, "1:1:x:y", 2, 250, 250);
//                                                └─────────┘  └┘
//                                   grid spacing 1x1, axes named "x"/"y"  label step=2
```

**Special case — trig/fraction labels** (suppress auto-numeric, let `addfractionaxislabels` control):
```php
$plot = showplot($funcs, xmin, xmax, ymin, ymax, "1000:1000:x:y", 1000, 300, 200);
$plot = addfractionaxislabels($plot, "pi/2", "x");
```

| Situation | `xlabels` param | `ylabels` param |
|---|---|---|
| Standard (integers) | `"1:1:x:y"` | `2` (every 2 units) |
| Fraction/trig axes | `"1000:1000:x:y"` | `1000` (suppress numeric) |
| Grid only, no axis name | `"1:1"` | `2` |

### Method 2 — `addlabel` after plot creation *(for `showasciisvg` or custom positions)*
```php
$plot = addlabel($plot, xmax + 0.3,  0,           "x", "black", "right");  // x-axis name
$plot = addlabel($plot, 0,           ymax + 0.5,  "y", "black", "above");  // y-axis name
```

---

## 2. MANDATORY RULE B: ALWAYS CALL `replacealttext`

After **every** `showplot`, `showasciisvg`, or `mergeplots`, immediately call `replacealttext`:
```php
$plot = showplot(...);
$plot = replacealttext($plot, "Highly detailed description: axes ranges, colors, shapes, labels, points.");
```
- ❌ Never write "Graph of a function."
- ✅ Write: "2D coordinate plane. x-axis labeled 'x' from -4 to 4, y-axis labeled 'y' from -1 to 10. Blue upward parabola f(x)=x² from x=-3 to x=3. Red closed dot at origin (0,0)."

## 3. VERIFIED FUNCTION SIGNATURES

### `showplot(funcs, [xmin], [xmax], [ymin], [ymax], [xlabels], [ylabels], [width], [height])`

| Param | Type | Default | Notes |
|---|---|---|---|
| `funcs` | `array\|string` | — | Array of plot command strings |
| `xmin` | `number` | `-5` | Supports `"0:"` prefix for first-quadrant |
| `xmax` | `number` | `5` | |
| `ymin` | `number` | `-5` | Supports `"0:"` prefix; `"auto:"` for auto-scale |
| `ymax` | `number` | `5` | Supports `"auto:"` |
| `xlabels` | `number\|string` | `1` | Use `"gx:gy:xlabel:ylabel"` string format to set grid + axis names |
| `ylabels` | `number` | `1` | Numeric label step (use `1000` to suppress) |
| `width` | `int` | `200` | Pixels |
| `height` | `int` | `200` | Pixels |

**`$funcs` element formats:**
```
// Function / curve:
"expression,color,xmin,xmax,startmarker,endmarker,strokewidth,strokedash"
// Examples:
"x^2,blue,-3,3,none,none,2"
"sin(x),red,-6.283,6.283"
"[x+t, t^2-1],blue,0,1,arrow,open"   // parametric

// Point:
"dot,x,y,closed|open,color,label,labelloc"
// Example:
"dot,0,0,closed,red,Origin,above"

// Text annotation:
"text,x,y,textstring,color,loc,angle"
// Example:
"text,2,4,f(x)=x^2,black,centered,0"
```

---

### `replacealttext(plot, alttext)` → `string`
Replaces or injects the alt attribute in the plot string. In text mode, returns `alttext` directly.

### `addplotborder(plot, left, bottom=5, right=5, top=5)` → `string`
Adds padding around the plot frame (pixels). Use when axis labels or tick numbers get clipped at the edge.
```php
$plot = addplotborder($plot, 20, 10, 10, 10);  // left=20, others=10
```

### `addfractionaxislabels(plot, step, axis='x')` → `string`
Replaces numeric tick labels with fraction/pi expressions.
- `step`: `"pi/2"`, `"1/3"`, `"2*pi/3"`, etc.
- **Prerequisite**: Set `xlabels="1000:1000:x:y"` and `ylabels=1000` in `showplot` to suppress conflicting auto-labels.
```php
$plot = showplot($funcs, -6.283, 6.283, -1.5, 1.5, "1000:1000:x:y", 1000, 300, 200);
$plot = addfractionaxislabels($plot, "pi/2", "x");
```

### `addlabel(plot, x, y, label, color='black', loc='', angle=0)` → `string`
Adds a text annotation at **graph coordinates** (mathematical space, not pixels).
```php
$plot = addlabel($plot, 1, 3,    "y=2x+1", "green", "right");  // function label
$plot = addlabel($plot, 4.3, 0,  "x",      "black", "right");  // axis name
$plot = addlabel($plot, 0, 10.5, "y",      "black", "above");  // axis name
```
`loc` values: `"right"`, `"left"`, `"above"`, `"below"`, `"centered"`.

### `addlabelabs(plot, x, y, label, ...)` → `string`
Same as `addlabel` but uses **absolute pixel coordinates** from the image corner.

## 4. COMBINING ARRAYS: `arraystodoteqns` + `connectthedots`

**Never** use `array_merge`. Draw each layer as a separate `showplot`, then combine with `mergeplots`.
Both sub-plots **must share identical bounds and axis label string** for coherent layering.

```php
$xpts = array(1, 2, 3, 4, 5);
$ypts = array(1, 4, 2, 5, 3);

// ✅ Correct pattern — separate showplot + mergeplots
$plot_dots  = showplot(arraystodoteqns($xpts, $ypts, "purple"),            0, 6, 0, 6, "1:1:x:y", 1, 250, 250);
$plot_lines = showplot(connectthedots($xpts, $ypts, "orange", 2, "", ""), 0, 6, 0, 6, "1:1:x:y", 1, 250, 250);
$plot = mergeplots($plot_dots, $plot_lines);
$plot = replacealttext($plot, "...");
```

### `arraystodoteqns(xArray, yArray, color='blue')` → `array<string>`
Returns an array of `"dot,x,y,closed,color"` strings, ready to pass into `showplot`.

### `connectthedots(xArray, yArray, color='black', thick=1, startdot='', enddot='')` → `array<string>`
Returns parametric line segment commands connecting consecutive points.
- `startdot` / `enddot`: `"open"`, `"closed"`, `"arrow"`, or `""`.

### `arraystodots(xArray, yArray)` → `array<string>`
Returns raw `"x,y"` coordinate strings (lower-level; used as input for other functions).

---

## 5. MERGING AND INJECTING

### `mergeplots(plot1, plot2, ...)` → `string`
Overlays multiple plot strings onto a single canvas. The **first plot's coordinate system** is used as the base. Always call `replacealttext` after merging.
```php
$plot = mergeplots($plot_a, $plot_b);
$plot = replacealttext($plot, "Combined description of both layers.");
```

### `adddrawcommand(plot, cmd)` → `string`
Injects a raw ASCIIMath/Asymptote draw command directly into the SVG payload.
- Single quotes in `cmd` are auto-converted to double quotes.
```php
$plot = adddrawcommand($plot, "strokeWidth=2; stroke='red'; rect([-1,-1],[1,1]);");
```

---

## 6. ALTERNATIVE RENDERER: `showasciisvg`

### `showasciisvg(script, width=200, height=200, alt=null)` → `string`
Renders a 2D image from a raw ASCIIMath script string.
- Line breaks in script are converted to semicolons automatically.
- **No built-in axis label format** → use `addlabel` afterward.

```php
$script = "setBorder(15); xMin=-3; xMax=3; yMin=-3; yMax=3; axes(); stroke='red'; circle([0,0], 2);";
$plot = showasciisvg($script, 220, 220, "Initial alt text.");
$plot = addlabel($plot, 3.2,  0,   "x", "black", "right");  // MANDATORY axis labels
$plot = addlabel($plot, 0,    3.2, "y", "black", "above");
$plot = replacealttext($plot, "Detailed description...");    // MANDATORY
```

## 7. STANDARD WORKFLOW

```php
// Step 1 — Build $funcs array
$funcs = array();
$funcs[] = "x^2,blue,-3,3,none,none,2";     // curve
$funcs[] = "dot,0,0,closed,red,O,above";     // point
$funcs[] = "text,2,4,f(x)=x^2,black,centered,0"; // text

// Step 2 — showplot with axis label string (MANDATORY)
$plot = showplot($funcs, -4, 4, -1, 10, "1:1:x:y", 2, 250, 250);

// Step 3 — Optional modifiers
$plot = addplotborder($plot, 20, 10, 10, 10);       // prevent clipping
$plot = addlabel($plot, 2.5, 9, "label", "gray");   // extra annotation

// Step 4 — replacealttext (MANDATORY, always last)
$plot = replacealttext($plot, "2D coordinate plane. x-axis labeled 'x' from -4 to 4, y-axis labeled 'y' from -1 to 10. Blue upward parabola f(x)=x^2 plotted from x=-3 to x=3. Red closed dot at origin (0,0).");
```

## 8. QUICK CHEATSHEET

### xlabels string format
```
"grid_x:grid_y"            → grid spacing only, no axis name
"grid_x:grid_y:xname:yname"→ grid spacing + axis names (PREFERRED)
"1000:1000:x:y"            → suppress numeric ticks + name axes (for addfractionaxislabels)
```

### Function Quick-Reference

| Function | Signature | Notes |
|---|---|---|
| `replacealttext` | `(plot, alttext)` | MANDATORY after every plot |
| `addplotborder` | `(plot, left, bottom=5, right=5, top=5)` | Pixels; prevents edge clip |
| `addfractionaxislabels` | `(plot, step, axis='x')` | Requires `1000:1000` in showplot |
| `addlabel` | `(plot, x, y, label, color='black', loc='', angle=0)` | Graph coords |
| `addlabelabs` | `(plot, x, y, label, ...)` | Pixel coords |
| `arraystodoteqns` | `(xArr, yArr, color='blue')` | Returns dot command array |
| `connectthedots` | `(xArr, yArr, color='black', thick=1, startdot='', enddot='')` | Returns line command array |
| `arraystodots` | `(xArr, yArr)` | Returns `"x,y"` string array |
| `mergeplots` | `(plot1, plot2, ...)` | Always `replacealttext` after |
| `adddrawcommand` | `(plot, cmd)` | Raw Asymptote inject; `'` → `"` auto |
| `showasciisvg` | `(script, width=200, height=200, alt=null)` | No built-in axis labels |

### Common Patterns

#### Pattern 1: Simple function plot
```php
$funcs = array();
$funcs[] = "x^2,blue,-3,3,none,none,2";
$funcs[] = "dot,1,1,closed,red";
$plot = showplot($funcs, -4, 4, -1, 10, "1:1:x:y", 2, 250, 250);
$plot = addplotborder($plot, 20, 10, 10, 10);
$plot = replacealttext($plot, "...");
```

#### Pattern 2: Trig plot with fraction axis labels
```php
$funcs = array();
$funcs[] = "sin(x),blue,-6.283,6.283";
$plot = showplot($funcs, -6.283, 6.283, -1.5, 1.5, "1000:1000:x:y", 1000, 300, 200);
$plot = addfractionaxislabels($plot, "pi/2", "x");
$plot = addplotborder($plot, 40, 10, 10, 10);
$plot = replacealttext($plot, "...");
```

#### Pattern 3: Scatter + lines (NO array_merge, NO foreach, NO while)
```php
$xpts = array(1, 2, 3, 4, 5);
$ypts = array(2, 4, 1, 5, 3);
$plot_dots  = showplot(arraystodoteqns($xpts, $ypts, "blue"),          0, 6, 0, 6, "1:1:x:y", 1, 250, 250);
$plot_lines = showplot(connectthedots($xpts, $ypts, "black", 2, "", ""), 0, 6, 0, 6, "1:1:x:y", 1, 250, 250);
$plot = mergeplots($plot_dots, $plot_lines);
$plot = replacealttext($plot, "...");
```

#### Pattern 4: showasciisvg with axis labels
```php
$script = "setBorder(15); xMin=-3; xMax=3; yMin=-3; yMax=3; axes(); stroke='blue'; circle([0,0],2);";
$plot = showasciisvg($script, 220, 220, "placeholder");
$plot = addlabel($plot, 3.2, 0,   "x", "black", "right");
$plot = addlabel($plot, 0,   3.2, "y", "black", "above");
$plot = replacealttext($plot, "...");
```

#### Pattern 5: mergeplots overlay
```php
// Both source plots must have compatible bounds
$plot = mergeplots($plot_a, $plot_b);
$plot = replacealttext($plot, "...");  // ALWAYS replacealttext after merge
```
