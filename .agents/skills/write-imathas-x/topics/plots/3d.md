# Reference: IMathAS 3D Plots (CalcPlot3D)

Provides instructions on how to dynamically generate interactive 3D plots in IMathAS using the `CalcPlot3Dembed` macro from the `plot3d` library. Useful for multivariable calculus, geometry, and vector visualization.

## 1. PRE-REQUISITES
Whenever you need to draw a 3D Plot, you **MUST** include the `plot3d` library at the top of `ZONE 0` in `control.php`:
```php
loadlibrary("plot3d");
```

## 2. FUNCTION SIGNATURE: `CalcPlot3Dembed`

```php
CalcPlot3Dembed(
    $funcs,       // [Array of Strings] List of 3D objects to render
    $width,       // [Int] Width of the iframe (e.g., 400)
    $height,      // [Int] Height of the iframe (e.g., 400)
    $xmin, $xmax, // [Float] X-axis bounds
    $ymin, $ymax, // [Float] Y-axis bounds
    $zmin, $zmax, // [Float] Z-axis bounds
    $xscl, $yscl, $zscl, // [Float] Axis scaling (typically 1, 1, 1)
    $zclipmin, $zclipmax // [Float] Z-clipping limits to prevent the top/bottom from being cut off
);
```

## 3. DEFINING 3D OBJECTS (THE `$funcs` ARRAY)
The first parameter `$funcs` is an array of strings. Each string follows a specific syntax depending on the object type.

### A. Implicit Surfaces (e.g., Ellipsoids, Spheres, Hyperboloids)
Simply write the equation.
*Syntax:* `"ax^2 + by^2 + cz^2 = k"`
*Example:* `"$a*x^2 + $b*y^2 + $c*z^2 = $k"`

### B. Implicit Planes
*Syntax:* `"Ax + By + Cz = D"`
*Example:* `"$n_x*x + $n_y*y + $n_z*z = $plane_d"`

### C. Points
*Syntax:* `"point, x, y, z, colorHex, size"`
*Example:* `"point, $x0, $y0, $z0, 0000FF, 5"` (Blue point, size 5)

### D. Spacecurves (Lines, Parametric Curves)
*Syntax:* `"curve, x(t), y(t), z(t), tmin, tmax, steps, width, colorHex"`
*Example:* `"curve, $x0 + $n_x*t, $y0 + $n_y*t, $z0 + $n_z*t, -1, 1, 50, 2, FF0000"` (Red line from t=-1 to 1)

## 4. HANDLING BOUNDING BOX AND CLIPPING (CRITICAL)
By default, `CalcPlot3Dembed` views a cube from `[-2, 2]` on all axes. If the random variables exceed these bounds, the plot will cleanly slice (clip) your geometry, making it look incorrect.

**Best Practice:** Dynamically calculate the maximum span of your surfaces and add padding, then pass these dynamically into the `CalcPlot3Dembed` limits, especially `$zclipmin` and `$zclipmax`.

## 5. ACCESSIBILITY (ALT TEXT)
Always wrap the final generated plot in `replacealttext()` and provide a screen-reader friendly description of what the 3D plot shows. This often involves injecting the randomized variables into the description.

## 6. COMPLETE GOLDEN EXAMPLE

### 6A. Minimal — Ellipsoid + Point

```php
// ZONE 0
loadlibrary("plot3d");

// ZONE 1
$a = rand(1, 3);
$b = rand(1, 4);
$c = rand(1, 5);
$x0 = rand(1, 3);
$y0 = rand(1, 3);
$z0 = rand(1, 3);
$k = $a * ($x0 * $x0) + $b * ($y0 * $y0) + $c * ($z0 * $z0);

// ZONE 2 — Calculate bounding box to prevent clipping
$rx = ceil(sqrt($k / $a)) + 2;
$ry = ceil(sqrt($k / $b)) + 2;
$rz = ceil(sqrt($k / $c)) + 2;
$plot_xmin = -$rx; $plot_xmax = $rx;
$plot_ymin = -$ry; $plot_ymax = $ry;
$plot_zmin = -$rz; $plot_zmax = $rz;

// Define functions array
$func_ellipsoid = "$a*x^2 + $b*y^2 + $c*z^2 = $k";
$func_point     = "point, $x0, $y0, $z0, 0000FF, 5";

$funcs = array($func_ellipsoid, $func_point);

// Render Plot
$plot = CalcPlot3Dembed(
    $funcs,
    400, 400,
    $plot_xmin, $plot_xmax,
    $plot_ymin, $plot_ymax,
    $plot_zmin, $plot_zmax,
    1, 1, 1,
    $plot_zmin, $plot_zmax
);

// Apply Alt Text for accessibility (MANDATORY)
$alt = "A 3D plot showing an ellipsoid centered at the origin. A point P is marked at ($x0, $y0, $z0).";
$plot = replacealttext($plot, $alt);
```

### 6B. Extended — Ellipsoid + Tangent Plane + Normal Line + Point

All 4 object types in one question (surface, plane, point, spacecurve):

```php
// ZONE 0
loadlibrary("plot3d");

// ZONE 1
$a = rand(1, 3);
$b = rand(1, 4);
$c = rand(1, 5);
$x0 = rand(1, 3);
$y0 = rand(1, 3);
$z0 = rand(1, 3);
$k = $a * ($x0 * $x0) + $b * ($y0 * $y0) + $c * ($z0 * $z0);

// Normal vector components and tangent plane constant
// n = (2a*x0, 2b*y0, 2c*z0), plane: n·(r - r0) = 0
$n_x = 2 * $a * $x0;
$n_y = 2 * $b * $y0;
$n_z = 2 * $c * $z0;
$plane_d = $n_x * $x0 + $n_y * $y0 + $n_z * $z0;

// ZONE 2 — Bounding box
$rx = ceil(sqrt($k / $a)) + 2;
$ry = ceil(sqrt($k / $b)) + 2;
$rz = ceil(sqrt($k / $c)) + 2;
$plot_xmin = -$rx; $plot_xmax = $rx;
$plot_ymin = -$ry; $plot_ymax = $ry;
$plot_zmin = -$rz; $plot_zmax = $rz;

// Define 4 objects
$func_ellipsoid = "$a*x^2 + $b*y^2 + $c*z^2 = $k";
$func_plane     = "$n_x*x + $n_y*y + $n_z*z = $plane_d";
$func_point     = "point, $x0, $y0, $z0, 0000FF, 5";
$func_line      = "curve, $x0 + $n_x*t, $y0 + $n_y*t, $z0 + $n_z*t, -1, 1, 50, 2, FF0000";

$funcsA = array($func_ellipsoid, $func_plane, $func_point, $func_line);

// Render Plot
$plotA = CalcPlot3Dembed(
    $funcsA,
    400, 400,
    $plot_xmin, $plot_xmax,
    $plot_ymin, $plot_ymax,
    $plot_zmin, $plot_zmax,
    1, 1, 1,
    $plot_zmin, $plot_zmax
);

// Alt Text (MANDATORY)
$altA = "A 3D plot showing an ellipsoid centered at the origin. A point P is marked at ($x0, $y0, $z0) on the surface. A flat blue plane is shown touching the ellipsoid exactly at point P. A red line passes through P and is oriented perpendicular to the plane.";
$plotA = replacealttext($plotA, $altA);
```
